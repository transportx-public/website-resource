Traffic Agent is a research prototype for transport analysis tasks. It brings data queries, map interaction, knowledge retrieval, and report drafting into one conversational workspace. Users can start with a specific transport question, inspect the relevant data and spatial evidence, and retain intermediate results during a multi-turn task.

The Agent selects data, spatial-analysis, retrieval, and visualization tools according to the question. Its outputs are intended to support analysis and review rather than replace domain judgement.
