Traffic Agent 是一个面向交通分析任务的研究原型。它把交通问数、地图交互、知识检索和报告整理放进同一个对话式工作台。用户可以从一个具体的交通问题出发，查看相关数据和空间证据，并在多轮任务中保留中间结果。

Agent 会根据问题选择数据查询、空间分析、检索和可视化工具。输出主要用于辅助分析与复核，不替代交通专业判断。
